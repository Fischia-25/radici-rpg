# 📌 Radici RPG

## Descrizione del Progetto
**Radici** è un Gioco di Ruolo (RPG) sviluppato in Java.
L'applicazione si concentra sulla gestione e la cura di un giardino, permettendo al giocatore di interagire con piante che evolvono attraverso vari stati (ad esempio: sana, curata, appassita, corrotta).
Il progetto è dotato di un'interfaccia grafica e include meccanismi per la persistenza dei dati.
L'architettura del codice è stata progettata seguendo i principi della programmazione orientata agli oggetti (come l'uso del pattern State) per garantire chiarezza, facilità di manutenzione ed estendibilità futura verso nuove funzionalità o piattaforme.
---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25 (LTS)
- Gradle

### Istruzioni

```bash
git clone https://github.com/Fischia-25/radici-rpg.git
cd radici-rpg
```

### Build del progetto
```bash
./gradlew build
```

### Esecuzione
```bash
./gradlew run
```
